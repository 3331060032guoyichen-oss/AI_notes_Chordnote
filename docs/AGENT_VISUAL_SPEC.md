# Agent 视觉构建与动效开发规范 (AGENT_VISUAL_SPEC.md)

> **适用范围**：知识库系统内建 Agent 角色形象、状态指示器及交互画板开发
> **核心美学**：新中式极简几何构成（Minimalist Geometric Collage） × 暗房网格坐标系 × 动态物理星云（Canvas 2D）
> **参考基准角色**：抚琴司天监 · Zhiyin（负责跨学科星网关联与知识唤醒）

## 1. 视觉基因与设计公理 (Design Tokens)

所有 Agent 角色视觉开发必须严格遵守以下色彩与空间约束，禁止使用写实插画渐变、圆滑拟物高光或第三方外部图片资源。

### 1.1 画板基底与坐标系

* **深空暗房底色 (`--bg-dark`)**：`#0a0c14`
* **司天监观测网格 (`--grid-line`)**：`rgba(92, 114, 178, 0.14)`，严格采用 `40px × 40px` 线性网格铺底，确立理性、克制、精密仪器的视觉基调。
* **舞台容器背景**：`radial-gradient(circle at 50% 45%, rgba(26, 36, 68, 0.68), rgba(8, 10, 18, 0.94))`

### 1.2 标准色板 (Color Palette)

## 2. 双层渲染架构 (Dual-Layer Rendering Architecture)

为兼顾几何边缘的绝对锐利与粒子流体的大范围弥漫，所有 Agent 舞台必须采用 **"前景 SVG + 背景 Canvas"** 的动静分离架构：

```text
.stage-card (相对定位容器, overflow: hidden)
 ├── .stage-title (z-index: 6, 顶部状态标题与英文副标)
 ├── .canvas-wrap (核心舞台区, height: 500px)
 │    ├── canvas.fx-canvas (z-index: 2, 绝对定位外扩铺满, pointer-events: none)
 │    │    └── 负责：体积感星云团、贝塞尔流光丝带、呼吸星宿拓扑网、漫天星尘与流星
 │    └── svg.agent-svg (z-index: 3, viewBox="0 0 500 460")
 │         └── 负责：星轨环、背景古典线稿暗纹、琉璃宫灯、几何角色躯干、核心道具与声波涟漪
 └── .status-footer (z-index: 6, 底部运行状态徽章与交互提示)
```

* **Canvas 外扩原则**：`canvas.fx-canvas` 需设置 `top: -50px; left: -20px; width: calc(100% + 40px); height: calc(100% + 70px)`，确保星云弥漫至卡片边缘时不产生生硬的矩形裁切感。

## 3. 几何人形与器物拆解公式 (Geometric Decomposition)

在 SVG 层绘制新 Agent 或维护现有形象时，必须遵循"去细节化、符号提炼"的几何降维法则：

### 3.1 角色本体构建

1. **头部与冠冕 (`.agent-head-group`)**：
   * **面部**：纯色正圆 `<circle cx="235" cy="168" r="26" fill="#f0ede6"/>`，彻底摒弃五官轮廓。
   * **神态**：仅用两条水平线段 `<line>` 表示双目（工作态 `y="164"` 凝神，静息态 `y="166"` 微闭）。
   * **官帽**：矩形帽身（`30×26`）叠加上下贯穿的泥金横簪（`stroke-width="3.2"`），体现古代文官/司天监规制。

2. **不对称几何躯干 (`.agent-body`)**：
   * 严禁使用曲线绘制衣褶。使用两个锐角 `<polygon>` 在颈部顶点（`235, 202`）交汇并向底部展开：
   * **左半身（深蓝三角）**：`points="235,202 145,420 265,420"`
   * **右半身（朱红折角四边形）**：`points="235,202 302,228 345,420 265,420"`，利用右侧肩部斜切角（`302, 228`）塑造端坐微倾的体态张力。

3. **动势手部 (`.hand-left` / `.hand-right`)**：
   * 使用简洁的四边梯形 `<polygon fill="#f0ede6">` 概括双手，依靠坐标角度区分"悬空拨弦"与"平搭静息"。

### 3.2 核心道具与背景暗纹

1. **主交互道具（以七弦古琴 `.qin-group` 为例）**：
   * 提炼为微倾的暗色长梯形外框，内嵌蓝（`#4a68d8`）、红（`#d93829`）、金（`#e6b85c`）三根平行弦线。

2. **状态伴随灯（八角琉璃宫灯 `.lantern-group`）**：
   * 由顶部挂环（`<circle>`）、二次贝塞尔曲线飞檐顶盖（`<path d="M 4 28 Q 22 22 36 10 ..."/>`）、三格灯身骨架与径向渐变光晕（`<radialGradient>`）构成。

3. **对角线平衡暗纹**：
   * 在舞台左下与右下角固定放置低透明度（工作态 `0.28` / 静息态 `0.18`）的单线古典器物线稿（如简册卷轴、铜制浑仪），丰富画面底蕴且不抢夺主体视线。

## 4. 状态机视觉映射表 (State-to-Visual Mapping)

Agent 仅保留「工作中 (Work)」**与**「静息中 (Rest)」两种纯粹状态，切换时必须形成强烈的动静反差：

| 视觉模块 | 工作中 (`work-mode` · 拨弦引星) | 静息中 (`rest-mode` · 抚琴守望) |
| --- | --- | --- |
| **双手姿态与动画** | 悬空倾斜；左手 `2.2s`、右手 `1.8s` 异步交错关键帧拨弦 (`handLeftPluck` / `handRightPluck`) | 动画清零；双手对称平搭于琴面 (`hands-rest`) |
| **头部与道具动态** | 头部 `3.6s` 周期微点 (`headNod`)；琴弦 `1.5s` 呼吸增亮；指尖激发 6 圈金色扩散声波涟漪 (`rippleExpand`) | 全部静止；古琴整体下沉 `translateY(4px) rotate(1deg)`，涟漪隐藏 |
| **八角琉璃宫灯** | 100% 不透明度，叠加 `drop-shadow` 金色光晕与 `3s` 上下悬浮呼吸动画 | 透明度降至 `0.55`，光晕半径收缩且无悬浮动画 |
| **弥漫星云团 (Canvas)** | **开启 (`screen` 滤色模式)**：14 团大半径（`0.26~0.42` 画布宽高）泥金/星河蓝/朱砂红/紫微径向渐变气团缓慢漂移呼吸 | **彻底关闭**：不渲染任何星云气团 |
| **星河丝带 (Canvas)** | **开启**：左翼 4 条、右翼 4 条及顶部苍穹拱桥流带（三次贝塞尔曲线 `cubicBezier`）从琴弦向全画幅喷薄延伸 | **彻底关闭**：不渲染任何流光丝带 |
| **星宿拓扑网 (Canvas)** | **显性共振**：18 个多彩星宿节点正弦浮动，31 条虚实相间的金色连线随时间脉冲呼吸 | **隐性收纳**：擦除全部拓扑连线与大节点 |
| **星尘与流星 (Canvas)** | **高频涌动**：145 颗沿 5 路贝塞尔轨道发散的流光粒子 + 95 颗全域上浮星尘 + 3 道周期划过的流星 | **静谧守望**：仅保留 36 颗固定位置的微弱呼吸背景星点（透明度 `0.15~0.40`） |

## 5. Canvas 核心特效算法规范

在编写或扩展工作态 Canvas 渲染逻辑（`renderWorkCanvas`）时，需严格按以下图层顺序由底向上绘制：

1. **第一层：大范围弥漫星云气团 (`drawDiffusedNebulaClouds`)**
   * 必须开启 `ctx.globalCompositeOperation = 'screen'`。
   * 每个气团基于正余弦函数计算轻微位移：`cx = c.rx * W + Math.sin(t * c.speed + c.phase) * 28`。
   * 使用三段式 `createRadialGradient`（中心高透明度 `pulseAlpha` -> 中段 `0.45 * pulseAlpha` -> 边缘 `0`），实现无边界氤氲感。

2. **第二层：宽幅跨度流光丝带 (`drawWideNebulaRibbons`)**
   * 同样在 `screen` 混合模式下，以左右抚琴手坐标（`W * 0.42, H * 0.70` 与 `W * 0.58, H * 0.68`）为起点，使用 `bezierCurveTo` 向左上、右上及顶部苍穹绘制 `lineWidth: 16~46` 的宽幅渐变曲线。

3. **第三层：星宿拓扑网与多轨流光粒子**
   * **连线奇偶虚实交替**：遍历 `constellationEdges` 时，对偶数索引启用 `ctx.setLineDash([4, 5])`，奇数索引保持实线，还原古星图与现代知识图谱结合的精密感。
   * **五路贝塞尔粒子插值**：流光粒子（`nebulaParticles`）通过标准三次贝塞尔公式 `cubicBezier(p0, p1, p2, p3, t)` 沿 `farLeft`、`upperLeft`、`centerTop`、`upperRight`、`farRight` 五条分支从琴弦飞向画布四周边缘，并在首尾两端通过 `Math.sin(t * Math.PI)` 实现平滑淡入淡出。
