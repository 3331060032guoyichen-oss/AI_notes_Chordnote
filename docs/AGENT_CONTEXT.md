# Agent 上下文与记忆（MVP）

## 当前行为

短时对话保存在服务端进程内存中，不写入独立的记忆文件。每次用户消息至助手完成回复（含全部工具调用和结果）是一轮。默认保留最近 10 轮，超过长度预算时提前整轮移除。失败的轮次不加入历史；已生成的待确认提议仍可在对话卡片中审阅。

成功请求返回 `trace.sessionId`，后续 `/api/agent/organize` 请求携带同一 `sessionId`。客户端不能提供历史正文。服务端验证会话归属，并拒绝同一会话的并发运行。历史事件只重放到模型上下文，不重新执行旧工具调用。

点击「新会话」会向 `POST /api/agent/session` 发送 `{ sessionId }`，追加结束日志后清除短时历史。关闭面板不结束会话；服务重启、六小时无活动或容量回收会使会话失效。最多保存 100 个会话，优先淘汰最久未使用的空闲会话。浏览器刷新后不恢复旧会话。待确认提议独立持久化，不随会话清除。

## 上下文顺序与预算

1. 宿主角色与权限边界（`manual.ts`）。
2. 当前 `Schema.md` 整理规则与用户偏好。
3. 最近五条提议或结束会话日志，以及最近十项提议的当前状态。
4. 当前用户可见、未归档文档的目录索引、本轮关键词检索片段和选中材料。
5. 最近 N 轮完整对话。
6. 当前用户输入。

Schema、日志和引用文档不能授予工具权限。运行时只开放白名单工具，没有原生文件、Shell 或数据库写入能力。

检索优先匹配标题与路径，其次正文；最多取五个命中，截取命中附近最多 500 字符，附带 ID、路径和截断标记。中文使用词组与相邻双字匹配。索引和片段都有长度限制，不依赖向量库。

预算采用 UTF-8 字节数保守估算，刻意多算中文，属于 byte-tokenizer 的上界估算，并非精确 Token 计数。单条输入和工具参数/结果预算为 8,000；历史序列化预算 32,000。每次模型请求还检查总预算，预留 4,096 输出空间，超出则返回可理解的错误，不发送过大请求。过长历史只整轮淘汰；单个过大完整轮次可能不被保留。Schema、目录、片段使用各自的截断预算。

| 环境变量 | 默认值 | 有效范围 |
| --- | --- | --- |
| `CHORDNOTE_HISTORY_TURNS` | 10 | 整数 1–50 |
| `CHORDNOTE_CONTEXT_TOKEN_BUDGET` | 65536 | 整数 16384–262144 |

应按照实际模型上下文容量调小预算；非法配置使用默认值。MVP 暂未增加可视化预算设置。

## 长时记忆与审批

沿用已有的 `Schema.md` 和 `audit_log`，不建立 `memory.md` 或记忆数据库。

偏好通过 `propose_preferences` 或 `propose_operations` 创建 `schema_preferences` 提议。工具必须提供本轮用户原话 `evidence`，服务端验证它出现在当前指令中。卡片展示原话、理由和完整替换内容；用户应审阅语义是否忠于原话。只允许替换 `## 用户偏好` 区块，保留其他规则，不能改变宿主权限。

用户点击「确认应用」后依次批准、应用。Schema 使用内容 hash 检查版本，知识页使用读取到的版本；过期提议变为 `stale`，不覆盖新编辑。批量确认逐项执行，失败项分别显示，已成功项不会回滚。审批期间输入框保持可编辑；模型运行中可以输入下一条，但需要等待当前轮完成后发送。

Schema 手动保存与提议应用共享进程级写队列。文件通过临时文件重命名保存，并写入提议回执，允许数据库提交失败后重试时识别已写内容。文件和 PGlite 不是同一个事务：崩溃可能暂时留下已修改的 Schema 与仍为 approved 的提议；应先重试该提议完成状态记录。如果此后又编辑了偏好、移除了回执，则旧提议按版本冲突处理，不强行覆盖。

审批、拒绝、应用与结束会话由宿主追加审计事件。注入模型的日志为时间加一句话操作记录，明确区分「批准」与「应用」。查询还记录读取和实际引用的文档 ID；引用以最终回答中出现来源 ID 为准。不会将模型猜测写成长期事实，也不后台调用模型自动总结对话。

## 验证

- `pnpm test:agent`：整轮历史、归属、并发、命中片段、偏好审批/版本/幂等，以及本地模拟模型驱动的真实 dsh 工具循环和 ACP 桥。
- `pnpm verify:db`：全部增量迁移与数据库约束。
- `pnpm test`：HTTP 回归；空闲端口时使用临时数据库及临时 Schema，测试结束清理。

需要和已有开发服务隔离时可设置 `REGRESSION_BASE_URL=http://localhost:4005`。自启动回归服务使用 `.tmp/regression-next` 构建缓存，不与正常开发服务共享 `.next`。
