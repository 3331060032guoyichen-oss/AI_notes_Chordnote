# AI Notes —— 问题清单与下一步

> 生成时间：2026-10-11。范围：部署验证 + 界面走查后的问题汇总与后续计划。
> 当前事实：线上站点 `https://hilarious-kheer-89a440.netlify.app` 已切到数据库存储层，线上回归 60/60 通过；`PATCH /api/raw/:id` 已上线（界面入口未接）。走查期间的临时数据已全部清理，所有业务表 0 行。

## 一、阻塞演示的问题（P0）

1. **线上没有 `DEEPSEEK_API_KEY`，主流程走不通。**
   - 现象：点"提出整理稿"直接返回「编辑助理尚未完成服务配置。原始记录仍然安全，请联系维护者。」
   - 影响：Raw → 知识页 这条核心路径在界面上完全无法完成；本轮知识页是靠手工写库才看到的。
   - 解决：在 Netlify 站点环境变量里加 `DEEPSEEK_API_KEY`，保存后重新部署。或者在界面加一个"手动收录"入口作为无 AI 时的兜底。

## 二、排版与布局问题（P1，演示前建议修）

2. **声音反馈浮层遮挡内容。** 固定在右下角、没有关闭按钮（只能"试听并开启 / 保持安静"），刷新后还会出现；900px 宽度下压住知识网络卡片和"查看知识网络"链接，窄屏下压住底部导航。
3. **Netlify 徽标压界面。** 右下角 "Powered by Netlify" 盖住声音浮层，移动端挡住底部导航的"更多"。演示前建议在站点设置里关闭。
4. **900px 宽度下右栏（编辑助理）整体消失且无入口。** 更窄的 420px 反而有底部导航（记录/网络/更多），中间存在一个断层。
5. **没有路由和深链接。** URL 始终是 `/`，刷新回到落地页、所有标签页丢失；无法把某张知识页的链接发给别人。属于结构改动，需单独立项。
6. **交叉引用卡片里目标标题居中。** `.relation-row` 是 grid，标题渲染成 `button`（浏览器按钮默认 `text-align: center`），和左对齐的说明文字不一致。改一行 CSS 即可。
7. **窄屏标签条拥挤。** 420px 下三个标签横向塞满、文字被截断。
8. **落地页标题对比度偏低。** 白色大标题压在浅色底上，教室投影下容易发灰；整屏摄影拼贴也与"大气简约、克制"的方向有张力。建议加一层浅色遮罩。

## 三、信息架构与一致性（P2）

9. **知识页不显示关键点与关键词。** 数据模型里有、AI 草稿也返回，界面只渲染了 concepts 芯片，`keyPoints` / `keywords` 未展示。
10. **右栏与设计规范不一致。** `AGENTS.md` 写的是"上下文面板：入链 / 出链 / 未链接提及 / 编辑助理"，实际只有编辑助理一块。
11. **原始记录的"编辑"入口缺失。** `PATCH /api/raw/:id` 已就绪，但界面上原始记录只有"提出整理稿 / 移除记录"，没有编辑原话的入口。

## 四、已验证可用的部分（保持）

- 排版：正文行高 1.75、卡片留白、字号层级统一；无渐变 / 玻璃拟态 / 大面积圆角装饰，整体克制。
- 交互：知识页内联编辑（点摘要 → 文本域 → 失焦自动保存 → 提示"修订已保存。"、版本 +1、写入修订记录）。
- 删除语义：移除原始记录有二次确认，且实际是归档（库内行保留、打 `archived_at` 标记），不是物理删除。
- 空状态与错误文案：记录消失后标签页优雅降级；AI 未配置时提示数据安全、不吓人。
- 响应式：420px 下侧栏替换为顶部抽屉 + 底部导航，布局可用（除上面提到的浮层/徽标遮挡）。
