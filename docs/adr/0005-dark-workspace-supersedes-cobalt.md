# 工作台整体转为深色，取代「主色保持钴蓝」

2026-10-10 曾定下「主色保持**钴蓝 `#4a5ac8`**，**不**往苹果系统蓝调」。此后提交 `32b5665 style(workspace): dark theme matching the Notipelago landing` 把工作台整体改成落地页那套「冷色极光」深色语言，`4dd5f61` 进一步把底色定到 `#030712`。**这是有意的改版，不是误伤**（提交标题写明"dark theme matching the Notipelago landing"）。

**决定**：界面主色**不是**钴蓝，而是**深海军蓝底 `#030712` + 紫 `#7c3aed`**。2026-10-10 那条「主色保持钴蓝」作废。

**为什么**：工作台要和落地页共用同一套视觉语言，否则首屏与工作区看起来像两个产品。

**后果**：

1. `AGENTS.md` 与 `docs/DESIGN_SYSTEM.md` 原记录的是一套**浅色**方案（矿物白 `#ecefeb` + 钴蓝），与代码早已不符，已就地更正。
2. **遗留冲突（尚未修）**：`:root` 改为深色之后，`@media (prefers-color-scheme: dark)` 里那份**更早的深色变体**（`#1d2026` + `#9aa7ff`）没有删除。于是系统设为浅色的用户拿到 `#030712`/`#7c3aed`，系统设为深色的用户拿到 `#1d2026`/`#9aa7ff`——**同一份代码、两种外观**。修法是删掉那个媒体查询，或让它与 `:root` 一致；改配色时必须同时处理这两处，否则改一半。
