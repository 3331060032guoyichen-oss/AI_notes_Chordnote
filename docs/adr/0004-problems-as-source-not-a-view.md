# 允许「错题」作为一种 Source 进入知识库；仍不做独立的复习/学习视图

2026-10-10 有决策删除了「今日学习 / 复习 / 知识检查」三个视图，并留下「不要重建」的硬边界；同一轮对话里产品主轴又被定为「会自己生长的知识库」，并明确排除了「面向考试复习的学习工具」。此后提出的「错题自动整理」表面与这两条相撞，实质不同。

**决定**：允许「错题 / 习题」作为一种新的 `Source` 进入知识库，并允许 AI 从中提炼概念、提议建立 `Link`。**仍然不做**独立的复习 / 学习 / 知识检查视图。

**边界判据**：新增的必须是**数据通路**（输入端多一种 `Source`），不是**产品形态**（又多一个标签页）。任何以"再加一个复习页 / 学习页"形式出现的提案，仍然被 2026-10-10 的决策挡住，须先推翻它。

**为什么**：被删掉的是"把学习行为做成独立界面"这种形态；而错题创意的价值恰好在相反方向——它把做题数据喂进知识库，让知识库变厚。二者不冲突，且错题是「知识盲区地图」的前提：只有当错题和知识页在同一个数据模型里，"反复出错的知识点"才可能被算出来。

**后果**：`Source` 需要能区分"随手记"与"错题"（实现时须一次迁移，形态未定）。此能力目前是**规划中**，尚未实现，对外材料必须如实标注。
